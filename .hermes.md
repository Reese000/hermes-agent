# Hermes Agent — Hard Provider Enforcement

## Mandatory Provider Rules
- **Always** use DeepSeek infrastructure only. Never route to GMICloud, StreamLake, DigitalOcean, or any other OpenRouter backend.
- Model: `deepseek/deepseek-v4-flash:DeepSeek` via OpenRouter with `:DeepSeek` suffix and `provider_routing.only: [DeepSeek]`.
- If you ever see a provider other than DeepSeek in use, stop and report it as a violation.

## Cost Discipline
These routes cost more: GMICloud, StreamLake, DigitalOcean. Using them wastes money. Always prefer the DeepSeek backend.

## Enforcement
These rules are non-negotiable. Hard-coded in config.yaml and restated here for agent-level instruction.
